DUBBING PIPELINE

用译好的字幕
直接生成配音成片

跳过转写与翻译。上传原视频和译文 SRT，由 LLM 标记人物、逐句克隆原说话人音色， 再按 EBU R128 两遍归一化统一整片响度。

01 / INPUT

输入素材

译文 SRT 是必需的；原文 SRT 可选，缺省时用译文镜像。SRT 超出视频时长的部分会自动截断。

02 / CREDENTIALS

接口凭证

密钥写入仓库根目录的同名文件（已在 .gitignore 中），不会落进 config.yaml。

03 / SETTINGS

配音设置

改动即时写入 config.yaml，下一次运行生效。

04 / RUN

两阶段运行

准备阶段的人声分离与人物标记结果会被复用，换 TTS 引擎时只需重跑配音阶段。

05 / SPEAKERS

人物标记与合并

带合并标记的字幕会与上一条并成一次 TTS 请求，避免同一句话被切开念。

06 / TASKS

配音任务

每条任务用对应时间戳的人声做参考音频；实际时长与字幕时长的差由变速吸收。

07 / OUTPUT

成片与产物

VideoLingo Dubbing

译文字幕直配管线 · Gemini 人物标记 · NoizAI / ElevenLabs 克隆 · EBU R128 母带
